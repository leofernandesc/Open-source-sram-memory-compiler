# Open-source SRAM Memory Compiler

Projeto de desenvolvimento de um compilador de memória SRAM single-port 6T para o PDK SKY130, utilizando ferramentas open-source.

O escopo atual prevê memórias com profundidades de 4, 8, 16 e 32 palavras, largura fixa de 8 bits e geração das principais views necessárias para integração e verificação: GDSII, LEF, Verilog e `.lib` simplificado.

## Ferramentas

- SKY130 / open_pdks
- Xschem
- ngspice
- Magic
- Netgen
- Python
- Icarus Verilog
- GTKWave
